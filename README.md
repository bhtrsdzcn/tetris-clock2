# ⏳ Pentotime — Tetris Clock

An authentic, retro-styled digital clock powered by falling Tetris (Pentomino) shapes.

🌐 **Live Website:** [pentotime.com](https://pentotime.com)

---

## ✨ Features

- **Dual Wells:** 10×15 Hours Well & 10×15 Minutes Well.
  - **Hours:** 1 complete Tetris shape = 1 Hour (12 shapes stack over 12 hours).
  - **Minutes:** 1 shape = 5 Minutes, with 1 single block lighting up each minute.
- **Gliding Preview:** Incoming shape glides down uncolored from the top 1 minute before locking in.
- **Top-of-the-Hour Clear:** Full line clear animation inspired by NES Tetris curtain wipe.
- **Interactive Controls:**
  - 12H / 24H time format toggle.
  - Turkish (TR) & English (EN) language support.
  - Multiple retro color themes (Classic, Game Boy, Cyberpunk, Matrix).
  - Authentic CRT TV scanline mode with phosphor glow.
  - Screensaver Fullscreen Mode (`F` or `Esc`).
  - Interactive Playground in the Info modal to test drops and line clears anytime.
